# RemoteKu v2.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Upgrade RemoteKu to v2.0 with the latest library versions, bundled premium typography, full Roku ECP support (live keyboard text entry, channel icons, Now Playing telemetry, hold-to-repeat, TV/Ultra hardware controls), a responsive side-by-side Command Deck UI with customizable favorite apps, and first-class macOS Menu Bar Tray, Touch Bar, Application Menu, and persistent window state.

**Architecture:** Main-process `RokuClient` (`roku-client.js`) handles all SSDP/subnet discovery and HTTP ECP calls with retry and in-memory icon caching (`axios` with `proxy: false`). `WindowStateManager` (`window-state.js`) persists window bounds and preferences. `main.js` manages the Electron `BrowserWindow`, macOS `Tray`, `Menu`, `TouchBar`, `globalShortcut`, and `powerMonitor`. Pure UI/domain helpers live in `renderer-logic.js` (shared between `renderer.js` and `node:test`), while `index.html`, `styles.css`, and `renderer.js` deliver the responsive Command Deck UI.

**Tech Stack:** Electron 45+, electron-builder 26.18+, Axios 1.21+, fast-xml-parser 5.12+, `@fontsource/space-grotesk`, `@fontsource/plus-jakarta-sans`, `@fontsource/jetbrains-mono`, Node.js built-in test runner (`node:test`).

**Spec:** `docs/superpowers/specs/2026-11-08-remoteku-v2-design.md`

## Global Constraints

- All HTTP requests in `RokuClient` must disable system proxy hijacking (`proxy: false`).
- All new features and helpers must be covered by unit tests using `node:test` and `node:assert/strict`.
- Fonts must be bundled locally from `@fontsource/*` with zero external requests to `fonts.googleapis.com`.
- Context isolation (`contextIsolation: true`, `nodeIntegration: false`) must remain strictly enforced.
- Every task must keep `npm test` passing with 0 errors.

## Review Focus

- Characters with special URI symbols (`/`, `?`, `&`, `#`, `%`, `+`, spaces, non-ASCII UTF-8) passed to `RokuClient.encodeLiteralKey` and `sendText` must be percent-encoded to UTF-8 `%XX` sequences so Roku ECP `/keypress/Lit_...` never fails or truncates.
- `scanLocalSubnetsForRoku` on systems with many virtual `utun*`/`bridge*` interfaces must skip virtual interfaces when physical LAN interfaces exist, while falling back if only virtual interfaces exist in a test/container environment.
- `getMediaPlayer()` must handle varying Roku XML responses (`position="24500 ms"`, `duration="120000 ms"`, missing attributes, or `state="none"`/`close`) without throwing or returning `NaN`.
- Toggling Mini Mode on and off must preserve and restore the user's custom resized normal window dimensions rather than resetting to hardcoded defaults.
- Keyboard shortcuts in the renderer must never fire Roku commands when focus is inside any text input (`#manual-host`, `#roku-text-input`, `#apps-search-input`) or when modifier keys (`metaKey`, `ctrlKey`, `altKey`) are pressed for standard shortcuts.
